Future update instructions

  1. Read the design-system instructions and component contract.
  2. Reuse the existing component with the same intent.
  3. Review new actions, destinations and flows in the workflow map first.
  4. Archive before editing. Preserve approved screens and frozen sources.
  5. Verify affected states, themes, large text, keyboard and localized copy.
  6. Update the map and contract when an approved convention changes.

Older tokens and reviewed component overrides differ in some body sizes, padding, field radii and colors. Those differences are recorded in the instructions. The catalog does not trigger a migration.
