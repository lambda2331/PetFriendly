Встречи без лишних действий

Два варианта для сравнения. Создание — только через «+» в заголовке. Детали раскрываются в списке. Чат открывается отдельно.

Рекомендация: вариант A. Три короткие вкладки видны сразу; дату выбирают кнопкой фильтра рядом с поиском. Вариант B оставляет больше места контенту, но требует дополнительного нажатия для смены участия.
Демонстрационные встречи и участники. Сообщения и фото остаются только в памяти макета; ничего не отправляется на сервер. Поля поиска и выбранные фильтры сохраняются при переключении оформления. История убрана из навигации этого макета; существующие данные и переписки сохраняются. Чат доступен участникам и организатору. Нет изменений Flutter, API или бизнес-правил.
