Первый вход · Studio

Интерактивный дизайн для согласования. Владелец, помощник или обе роли — один аккаунт. Данные и фото остаются в памяти макета.

Путь нового пользователя

Выбор роли → короткий профиль → питомец по желанию или условия и доступность помощника → первый полезный шаг. Нажимайте «Продолжить» внутри телефона: введённые данные сохраняются при возврате.

Город предлагается по геопозиции после разрешения пользователя; поиск и ручной ввод остаются запасным вариантом. Геопозиция в этом макете условная, реальные координаты не запрашиваются. Доступ к уведомлениям запрашивается после включения пользователем. Публично виден район, а не адрес. Помощнику не нужен свой питомец.
