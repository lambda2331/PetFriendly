# PetFriendly

## Platform and purpose

The product is a Flutter mobile community for pet owners on iOS and Android. It combines nearby places, people, interest groups, meetings, walking help and chat. Minsk, Belarus is the initial market. The existing native interface is primarily Russian.

## Portfolio

The user is preparing a Design Engineer portfolio in English and confirmed equal emphasis on design and development. The public case study and HTML interaction study live in `portfolio/` and deploy to GitHub Pages. The browser adaptation uses fictional data and follows current Flutter main-screen composition; native services are not connected.

## Stack

Native: Flutter/Dart, Riverpod, go_router, Supabase, Mapbox and an OpenStreetMap catalog. Portfolio: static HTML/CSS/JavaScript, bundled assets and a Python generator; GitHub Pages is the requested hosting destination.
