1. Mapbox готов: аккаунт demo access без платёжного способа, Default public token в ignored app.ios.local.json/app.android.local.json; реальные карты обеих платформ проверены. Standard access не активировался.
2. Google подключён: настоящий вход и восстановление сессии проверены на iOS, клиентский флаг включён в staging обеих платформ. Android OAuth отдельно ещё не проверен. Apple и Telegram OIDC ожидают настройки.
3. Firebase project и клиентские параметры обеих платформ готовы, инициализация на iOS проверена. Остаются APNs, серверный service account, расписание dispatch-notifications и доставка на устройствах.
4. SMTP и настройка распространения закрытым тестерам. Cloud Supabase развёрнут; Android APK/AAB подписаны локально, дистрибуция не публиковалась.

Не требуется дизайн-ревью для выполнения этих настроек. До публичного выпуска остаются ранее отложенные правила и сроки хранения/удаления резервных копий, moderation workflow, проверка восстановления аккаунтов и полный security review. Локальные проверки не являются сертификацией безопасности.

Сценарий выгула в демо содержит явно помеченную имитацию действий помощника. В серверном режиме переходы проверяются по роли; рейтинг не записывается клиентом. Live tracking и платежи не включены. Private upload/read фото проверены локально и в staging; проверка текущего доступа выполняется внутри функций, прямое клиентское чтение Storage закрыто.
